| EAT Hooking               | Модификация структуры файла                       | Замена указателей в Export Address Table                                                                       | Просто, детерминировано, влияет на всех вызывающих | Ломает ожидания (ASLR), редкое использование                                            |

| Page Guard Hooking        | Злоупотребление                                   | Установка PAGE_GUARD флага на страницу + обработка исключений                                                  | Нет модификации кода                               | Потери производительности, шумно                                                        |
| Thread Context Hooking    | Манипуляция с контекстом потока                   | Изменение RIP через Get/SetThreadContext                                                                       | Нет модификации кода                               | Только на поток, очень нестабильно                                                      |
| APC Injection Hooking     | Манипуляция с контекстом потока                   | Очередь APC                                                                                                    | Асинхронно, скрытно                                | Поток должен иметь alertable state                                                      |
| Thread Suspension Hooking | Манипуляция с контекстом потока                   | Приостановка потока с последующей модификацией контекста потока или кода после чего работа потока продолжается | Полный контроль                                    | Race conditions, очень нестабильно                                                      |
| Fiber / UMS Hooking       | Злоупотребление                                   | Перехват user-mode планировщика                                                                                | Очень скрытно                                      | Сложно реализуемо, редко Fiber можно встретить                                          |
| Return Address Spoofing   | Злоупотребление / Манипуляция с контекстом потока | Подмена адреса возврата                                                                                        | Очень скрытно                                      | Очень нестабильно, перехват будет заточен под конкретные условия конкретного приложения |
