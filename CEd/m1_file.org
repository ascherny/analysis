** PE header :header:pe:
*** COFF File Header
| Machine              | Указывает архитектуру исполняемого файла (AMD64, ARM64, MIPS и т. д.)                                                                                                             |
| NumberOfSections     | Указывает количество секций в исполняемом файле.                                                                                                                                  |
| TimeDateStamp        | Время создания файла (начиная с 1 января 1970 00:00).                                                                                                                             |
| PointerToSymbolTable | Указатель на символьную таблицу COFF. Устаревшее поле, так как отладочная информация COFF больше не используется, а само поле инициализировано нулями.                            |
| SizeOfOptionalHeader | Количество записей в символьной таблице COFF. Использовалось для поиска таблицы строк, что располагалась после символьной таблицы. Устаревшее поле.                               |
| Characteristics      | Характеристики, указывающие на атрибуты файла (например, что программа поддерживает адреса больше 2 гигабайт, что исполняемый файл системный или что он динамическая библиотека). |

| Magic                       | Целочисленное указывает, является ли файл PE32 (0x10B) или PE32+ (0x20B). Их разница в том, что последний может поддерживать 64-битные адреса. | SizeOfInitializedData       | Размер инициализированной секции данных (.data) или же сумма всех секций с инициализированными данными.                                                                                                                                                                                                                                     |
| SizeOfUninitializedData     | Размер неинициализированной секции данных (.bss) или же сумма всех секций с неинициализированными данными.                                                                                                                                                                                                                                  |

| Win32VersionValue           | Зарезервированное поле, обязано быть 0.                                                                                                                                                                                                                                                                                                     |
| SizeOfImage                 | Размер исполняемого файла в байтах, включая все заголовки. *** Directory Header
Смещение до таблиц относительно базового адреса и размер таблиц
#+begin_src c
typedef struct _IMAGE_DATA_DIRECTORY {
    uint32_t   VirtualAddress;
    uint32_t   Size;
} IMAGE_DATA_DIRECTORY, *PIMAGE_DATA_DIRECTORY;
#+end_src
По стандарту, все таблицы расположены в следующем порядке:

Таблица экспортов (секция .edata).
Таблица импортов (секция .idata).
Таблица ресурсов (секция .rsrc).
Таблица исключений (секция .pdata).
Таблица сертификата с электронной подписью файла.
Таблица релокаций (секция .reloc).
Отладочная таблица (секция .debug).
Архитектурная таблица (зарезервирована, обязана быть 0).
GlobalPtr таблица - RVA значения, которое должно быть сохранено GP-регистром (Global Pointer Register).
TLS таблица (Thread Local Storage, секция .tls).
Таблица конфигурации загрузчика.
Bound Import таблица.
IAT (Import Address Table), не стоит путать с таблицей импортов.
Таблица отложенных импортов.

** Процесс загрузки исполняемого файла

1. Прочитать заголовки исполняемого файла.
2. Сохранить информацию о размере, секциях, базовом адресе, таблицах исполняемого файла.
3. Выделить адрес и количество страниц памяти, удовлетворяющие требованиям исполняемого файла.
4. Перенести секции исполняемого файла в выделенный участок памяти.
5. Обработать необходимые таблицы, например, таблицу импортов и релокаций.
6. Создать процесс и запустить исполняемый файл.
