#+title: Compile Utils

* Llvm + utils :llvm:
** llvm cheatsheet :llvm:
*** Out
-o <file>	Выходной файл
-S	Только ассемблер (.s)
    -emit-llvm	генерация промежуточного llvm IR
-c	Только объектный файл (.o) без линковки
-E	Только препроцессинг (вывод на stdout)
-###	Показать команды линковки (не выполняя)
-v	Подробный вывод (версия, пути, вызовы)
-### -v	Максимально подробно
*** Оптимизации
-O0	Нет оптимизации (по умолчанию)
-O1	Базовая оптимизация
-O2	Агрессивная оптимизация (обычный выбор)
-O3	Максимальная оптимизация (может увеличить бинарник)
-Os	Оптимизация по размеру
-Oz	Ещё сильнее по размеру (для мобильных)
-Ofast	-O3 + быстрые мат. операции (опасно)
-flto	Link-Time Optimization
-ffast-math	Небезопасные оптимизации математики

*** Стандарты
-std=c99	C99 стандарт
-std=c11	C11
-std=c17	C17
-std=c++11	C++11
-std=c++14	C++14
-std=c++17	C++17
-std=c++20	C++20
-std=gnu99	C99 с расширениями GNU
-pedantic	Строгое следование стандарту
-pedantic-errors	Как выше, но ошибки вместо варнингов

*** IR
%x	Локальная переменная (виртуальный регистр)
@x	Глобальная переменная
alloca	Выделить память на стеке
load	Прочитать из памяти
store	Записать в память
br	Безусловный/условный переход
icmp	Сравнение целых чисел
** llvm sandbox :compile:llvm:

    C source
    ↓
    Clang Frontend
    ↓
    LLVM IR
    ↓
    LLVM x86-64 Backend
    ↓
    ELF relocatable object (.o)
