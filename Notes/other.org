** Файловый дескриптор
Таблица дескрипторов это объект ядра принадлежащий процессу
У каждого процесса есть таблица дескрипторов - массив чисел который связан с каждым из открытых файлов
Системные вызовы принимают и возвращают индексы этого массива

Свойство направления RWU задается уже системным вызовом который принимает fd
И реализует проверку прав на объект

#+begin_src shell  :results output
lsof | grep "emacs"
#+end_src
