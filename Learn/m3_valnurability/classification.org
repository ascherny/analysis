** Command Injection
:PROPERTIES:
:CUSTOM_ID: Command Injection
:END:

Алгоритм:
1. Сначала определение точек входа, откуда приложение получает данные
Пользовательский ввод, параметры окружения, файлы, сеть
2. Отслеживание потока выполнения и выхода
    Важны функции передающие аргументы командным интерперетаторам или формирующие выполнение
+ C/C++:
    system(), popen();
    exec(), execl(), execvp(), CreateProcess(), ShellExecute();

+ C#:
    System.Diagnostics.Process.Start();

+ Python:
    os.system();
    os.popen();
    subprocess.call(), subprocess.Popen(), subprocess.run() с параметром shell=True;

+ Java:
    Runtime.getRuntime().exec();
    ProcessBuilder

3. Проверка валидации входных данных
