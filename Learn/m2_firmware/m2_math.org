Душеполезно повторить

- Множество всех возможных исходов называется пространством элементарных исходов и обозначается $\Omega$
- Событие - подмножество исходов
- Вероятность - функция $P$ которая сопоставляет каждому событию число $P(A) \in [0,1]$
    Вероятностная функция удовлетворяет аксиомам Колмагорова
    1. $P(\Omega) = 1$
    2. $P(A) >= 0$
    3. Если события попарно не пересекаются то функция аддитивна $P(A_1 \cup A_2 \cup \dots A_n) = P(A_1)+P(A_2)+...+P(A_n)
    4. Для равновероятных исходов вероятность P(A) = $|A|/|\Omega|$
- Случайная величина $X$ - функция которая каждому исходу $\omega \in \Omega$ сопоставояет число $X(\omega)$


С точки зрения теории вероятностей энтропия Шеннона - это математическое ожидание случайной величины информации


Пусть $H_n(p_1, \dots, p_n)$  функция, сопоставляющая распределению вероятностей $(p_1, \dots, p_n)$,
где $\sum p_i = 1$, $p_i \ge 0$.
число которое будет называться мерой неопределенности

Потребуем от $H$ выполнение трех аксиом

1. Непрерывность
   $H_n(p_1,\dots,p_n)$ непрерывна по всем аргументам
2. Монотонность
   Пусть $A(n)=H_n(1/n,\dots,1/n)$ - неопределенность выбора одного из $n$ равновероятных исходов,
   тогда $A(n)$ строго возрастает по n
3. Аддитивность
   Если процесс выбора из $N$ равномерных исходов эквивалентен двухшаговому процессу
   выбор одной из $k$ групп с вероятностями $p_1,\dots,p_k$
